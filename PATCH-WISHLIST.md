# Possible CFW Features

## Five-band parametric EQ

Investigate whether the EQ can support five custom bands instead of the current
three.

## Add to Queue / Play Next

Add a song menu action to play a track next or add it to the queue. Keep playback
order and the prepared next track correct with shuffle and repeat enabled.

## FairPlay DRM

Investigate full removal, or a narrower approach using legitimately available 
tickets/authorization material from preservation projects.

## Phase game revival

Invesigate an easier way to sync Phase compatible songs.

## Resource and font overrides

Explore loading selected resources or fonts from regular files.

## Debug facilities

Investigate whether RTXCbug or diagnostic interfaces can help with debugging.

## FLAC and other audio formats

Investigate the audio engine to see whether it can support formats such as FLAC.
